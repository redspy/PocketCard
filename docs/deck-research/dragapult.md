# 드래펄트 ex — 2026 코리안리그 S1 시니어 우승

## 요약
드래펄트 ex 스펙터다이브(200 + 상대 벤치 카운터 6개 배분)로 매 턴 여러 마리를 노리고, 야느와르몽/미라몽 커스 봄·이야후·루차불의
카운터로 한 턴 다수 프라이즈를 만드는 2진화 스프레드 덱. 초반엔 꼬몽울 아이템 락과 모야모로 상대 전개를 늦춘다.

## 핵심 카드 [카드]
- 드라꼰 SV8a_118: 드래곤 HP70, 약점 없음. 40(불꽃+초)
- 드래런치 SV8a_119: HP90. 특성 정찰 지령 — 덱 위 2장 보고 1장 패로, 1장 덱 아래
- 드래펄트 ex SV6_120: HP320, 드래곤, 약점·저항 없음, 후퇴1, 테라스탈(벤치에서 기술 데미지 무효).
  제트헤드(무색1) 70 / 스펙터다이브(불꽃+초) 200 + 상대 벤치에 카운터 6개 자유 배분
- 해골몽 SV8a_064(HP60, 트래쉬의 해골몽 3장까지 벤치로) → 미라몽 SV8a_065(커스 봄: 자기 기절, 카운터 5개)
  → 야느와르몽 SV8a_066(HP160, 커스 봄 카운터 13개=130, 그림자묶기 150+후퇴불가). 이 라인은 악 약점
- 꼬몽울 SV8a_001: 풀 HP30, 무색1로 10 + 상대 다음 턴 아이템 사용 불가
- 이야후 SV8a_075: 아드레나 브레인(악 에너지 필요) — 내 카운터 3개를 상대에게. 이 덱은 악 에너지가 없어 **루미너스 에너지로 조건 충족**
- 루차불 SV8a_084: 패에서 벤치로 낼 때 상대 벤치 2마리에 카운터 1개씩
- 다투곰 붉은 달 ex SV8a_225: HP260, 상대가 가져간 프라이즈 1장당 비용 -1, 블러드문 240
- 라티아스 ex SV7a_078: 스카이라인 — 내 기본 포켓몬 후퇴비 0
- 기로치 ex SV6a_089: 역이용 3장 드로우, 크루얼애로 100(벤치 지정 가능)
- 투희 ×2(진화 포켓몬+에너지 서치), 릴리에의 결심 ×4, 모야모 ×4, 카운터 캐처 ×3, 재밍타워 ×2(양쪽 도구 무효)
- 네오 어퍼 에너지(ACE SPEC): 2진화에 붙으면 모든 타입 2개분 → 1장으로 스펙터다이브 가능
- 루미너스 에너지 ×3: 모든 타입 1개분(다른 특수 에너지와 같이 붙으면 무색 1개)

## 게임 플랜 [외부+추론]
- 후공 선호. 후공 1턴 꼬몽울로 아이템 락, 포핀으로 드라꼰 2 + 해골몽 전개
- 선공 1턴: 드라꼰 최대 전개, 꼬몽울(HP30) 혼자 앞에 남기지 않기
- 2턴: 드래런치 2마리로 정찰 지령 2회, 투희로 드래펄트+에너지
- 중반: 매 턴 스펙터다이브. 카운터 6개는 저HP 기본/1진화 정리 또는 커스 봄 킬각 준비
- 후반: 모야모로 상대 패 압박, 야느와르몽 130 + 200 + 루차불/이야후로 2~4프라이즈 턴

## 팁
1. 200 + 커스 봄 130 = 330 → 리자몽 ex(330)·가디안 ex(310)·드래펄트 ex(320) 원킬
2. 커스 봄은 상대에게 프라이즈 1장을 줌 → 프라이즈 수 조절로 카운터 캐처 조건 만들기
3. 이야후 + 루미너스: 드래펄트가 맞은 카운터 3개를 되돌려 체력 관리 + 추가 킬각
4. 흔한 실수 [외부]: 너무 이른 공격, 해골몽 과다 전개(미러에서 스프레드에 잡힘)

## 강점/약점
- 강점: 본체 HP320 무약점, 벤치 스프레드, 한 턴 다수 프라이즈, 초반 방해
- 약점: 2진화라 느림, 드라꼰 HP70, 에너지 7장(초2·불꽃1·네오어퍼1·루미너스3), 초 라인 악 약점, 상대 이야후의 카운터 역이용
