# 파쪼옥 (Joltik Box) — 2026 코리안리그 S3 시니어 우승

## 요약
파쪼옥의 1에너지 기술 파쪼차지로 덱에서 풀 2장 + 번개 2장을 한꺼번에 붙이고, 2턴째부터 무쇠손·피카츄·미라이돈·무쇠잎새 등
기본 ex 중 상대에게 맞는 공격수를 골라 치는 툴박스 덱.
